This starter workspace contains original configuration and documentation
templates. It does not include BookCars source code.

Before copying, modifying, or distributing BookCars code:
1. Read the license file in the exact commit you use.
2. Preserve required copyright and license notices.
3. Inventory third-party dependencies and their licenses.
4. Check any assets, fonts, icons, and generated code separately.
5. Ask qualified legal counsel if the intended commercial distribution or
   service model raises licensing questions.

dependency has identical licensing terms.
